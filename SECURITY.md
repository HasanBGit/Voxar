# Security policy

voxar is pre-alpha and not intended for production use yet.

To report a vulnerability, do not open a public issue. Email **hassanhbarmandah@gmail.com** with a description and steps to reproduce. Do not include personal audio. Expect an acknowledgement; this is a pre-alpha project maintained by one person, so there is no guaranteed response time.

Audio can contain personal data. Anything that sends audio off-device must be opt-in and documented.
